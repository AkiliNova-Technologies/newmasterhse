# NewMaster Content Studio

This is the separate Sanity Studio used by authorised NewMaster content administrators. Run `npm install` in this folder once, then start it from the repository root with `npm run studio`; deploy it with `npm run studio:deploy` after logging in to the correct Sanity account.

Studio authorisation is controlled in the Sanity project at sanity.io/manage. Invite editors there; never give them a website deployment credential or an API write token.
